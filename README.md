# Expense Manager

A simple **offline-first** app to track income and expenses locally in your browser.

## Features

- **Dashboard** — Financial overview, expense by category, recent transactions
- **Add Transaction** — Income & expense with categories and recurring support
- **Calendar** — Daily income/expense view with color coding
- **Expense Explorer** — Search, filter, sort, paginate, export CSV/Excel
- **Calculators** — Expense split, savings goal, 50/30/20 budget planner
- **Reports** — Category breakdown chart

## Quick Start

```bash
npm install
npm run dev
```

## Tech

React 19 · TypeScript · Vite · Redux Toolkit · IndexedDB (Dexie) · MUI · Recharts
